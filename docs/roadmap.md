# Roadmap

## Phase 0

- isolate repo
- capture discovery findings
- define domain model
- scaffold API and test harness

## Phase 1

- ingest AEMO controlled product data
- build historical IRSR reconstruction engine
- import historical auction outcomes
- compare fair values with realised distributions and clears

## Phase 2

- add forward scenario engine
- integrate outage, constraint, and flow sensitivities
- calibrate confidence bands
- add valuation lineage endpoints

## Phase 3

- generate target bid curves for pilot auctions
- add operator approval workflow
- build reconciliation and reporting

## Phase 4

- support indicative OTC pricing
- design assignment workflow orchestration
- evaluate marketplace and agency models
