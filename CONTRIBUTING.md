# Contributing to HAIMOS

Read `VISION.md` before beginning any work.

## Core Principles

- Every task must improve investment decision quality.
- One mechanism per research cycle.
- Pre-register hypotheses.
- Preserve point-in-time integrity.
- Prefer explainability over complexity.
- Never optimise before understanding.

## Engineering Rules

- Small commits.
- One logical change per commit.
- Tests before merge.
- Preserve Digital Twin integrity.
- Never bypass reproducibility.

## Research Rules

- Evidence updates the Knowledge Graph.
- Failed experiments are valuable.
- Never move thresholds after seeing results.
- Every accepted law must include boundary conditions.

## Decision Rule

If a proposed feature does not improve investment decisions, it does not belong in HAIMOS.
